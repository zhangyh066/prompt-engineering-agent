# PEA 最终模拟联调报告

## 结束状态

**模拟流程已执行到终点；真实 API、真实人工和真实产品优越性验收仍未完成。**

按项目负责人要求，API、人工评审和外部服务均由子 Agent 模拟。所有生成与评审结果只用于调试工作流、策略和统计，不构成真实正确率提升或竞品优劣证据。

## 方法与盲评边界

- 原始组与优化组由独立子 Agent 回答，生成输入不包含参考答案。
- 主流程在生成后读取参考答案并计算 Exact Match、Token F1 和成对统计。
- dev 选择后才访问最终 test；test SHA256 已校验并记录。
- 最终两名盲评子 Agent 只看到随机左右位置的输出，看不到原始/PEA标签。
- 子 Agent 的具体底层型号与强度不可指定，Token、成本和延迟不可核验。

## Dev 候选选择

最小策略与默认策略在 8 条 dev 上生成了完全相同的 Prompt，因此该消融被标记为不确定，没有根据子 Agent 输出差异宣称策略优劣。

随后使用真正不同的通用改写 Prompt 对照：

| 组别 | 平均参考分 |
|---|---:|
| 原始 | 0.3268 |
| PEA 默认 | 0.3151 |
| 通用改写 | 0.3030 |

按预先声明的规则，为最终模拟选择 PEA 默认组。该选择不是实际质量结论。

## 上下文噪声修复

首次子 Agent 联调中，优化组参考均分由原始组 0.3268 降至 0.2478。负面结果被保留并用于定位：长上下文中的关键词和长度干扰了任务分类与复杂度，导致简单抽取被误加研究角色和拆解。

修复后优化组均分回升至 0.3151，但与原始组差异置信区间仍跨 0，不能据此声称等效或提升。

这两名评审是 LLM 子 Agent，不是真实人工，不能作为最终人工可用性证据。

## 最终结论

- Harness 的生成、候选选择、最终访问、参考评分、配对统计和盲评汇总已完整跑通。
- 当前模拟没有证明 PEA 的真实正确率提升。
- 当前模拟没有证明 PEA 优于 Promptfoo、DSPy、PromptPerfect 或其他实际产品。
- 最终 test 已用于本次模拟，禁止继续据此调参。后续正式评估应使用新的未见 holdout，避免模拟访问造成选择偏差。
